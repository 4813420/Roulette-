# Lucky Roulette

GitHub Pages-ready single-file web app.

## Upload to GitHub
1. Create a new repository.
2. Upload `index.html`.
3. Repository Settings → Pages.
4. Under Build and deployment choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Open the Pages URL GitHub gives you.

Each line in the text box is one roulette field. The first field is green; the rest alternate red/black. The wheel spins and a white roulette-style ball animates around the rim before the result is shown.
